# Herramientas de mantenimiento

Para los videos, abre **Abrir demo defensa.cmd** en la carpeta principal del
proyecto. Ahí se prepara la base y se completa la agenda antes de abrir el
navegador. Consulta la [guía de defensa](../../docs/DEFENSA-DATOS.md).

| Si necesitas… | Abre en esta carpeta |
| --- | --- |
| Abrir la demo habitual en el puerto 8000 | **Abrir Kiddo Spark.cmd** |
| Cerrar la demo habitual | **Apagar Kiddo Spark.cmd** |
| Completar los horarios de defensa con el servidor apagado | **Preparar demo defensa.cmd** |
| Empezar con otra base de defensa y conservar la anterior | **Restablecer demo defensa.cmd** |
| Cargar el escenario pequeño en la demo habitual | **Cargar datos demo.cmd** |
| Preparar o iniciar la demo habitual desde PowerShell | **instalar_local.ps1** o **iniciar_local.ps1** |
| Abrir una demo remota privada | **compartir_local.ps1**. Sigue las [instrucciones del túnel](../../README.md#compartir-una-demo-remota-con-acceso-privado). |

Para cerrar la demo de defensa, pulsa **Ctrl+C** en la ventana que la inició.
